# Weather-checking-API
Auto weather bot

## C++ Item Profit Calculator
A standalone interactive calculator is provided in `item_profit_calculator.cpp`.

### Build
```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic item_profit_calculator.cpp -o item_profit_calculator
```

### Run
```bash
./item_profit_calculator
```

Example non-interactive invocation:
```bash
printf "10\n15\n3\n8.25\n" | ./item_profit_calculator
```
